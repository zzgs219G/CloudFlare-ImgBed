# 历史修改记录

## 问题 1：CNB 渠道上传后，浏览器打开链接出现项目自带 404 页面

**日期**：2026-09-21
**状态**：已修复（代码已改，待部署 + 清缓存）

### 现象（用户实测）

- 用 CNB 渠道上传图片，拿到自定义链接（如 `https://img.614118.xyz/file/1789970676695_img3038.webp`）
- 用浏览器直接打开 → 出现项目自带的"精美 404 页面"
- 后台缩略图、预览图正常加载；后台"下载"按钮正常下载到图片
- 结论规律：**不用浏览器打开就正常，用浏览器打开就 404**

### 根因（curl 实测确认）

1. 普通 curl 请求 `/file/xxx.webp` → 正常 302 跳转到 CNB 直链，能拿到图片 ✅
2. 带浏览器特征头（`Sec-Fetch-Dest: document` 等）请求同一 URL → 直接返回 **`cf-cache-status: HIT` 的 `text/html`**（SPA 的 index.html），根本没回源到 Worker ❌

**结论**：Cloudflare 边缘缓存把一份 SPA 的 HTML 缓存到了 `/file/xxx.webp` 这个 URL 上（响应头标签 `cf-cache-status: HIT`、`Content-Type: text/html`）。浏览器导航请求命中这份脏缓存，前端路由里没有 `/file/` 页面，于是渲染出项目自带的 404 页面。

- 这就是以前 AI 说的"标签问题"：是响应头标签（缓存状态、Content-Type）把错误内容标记到了图片 URL 上，重新部署时缓存重新产生，问题就复现。
- 后台正常是因为：后台预览/下载走的请求路径和缓存变体不同，没有命中脏缓存。

### 修复方案（治本 + 兜底）

核心思路：**CNB 渠道对用户直接返回国内直链，浏览器不再经过 Cloudflare 的 `/file/` 路由**，脏缓存问题彻底绕开；`/file/` 路由保留作兜底（302 跳转 CNB 直链）。

改动 3 个文件：

| 文件 | 改动 |
|---|---|
| `CloudFlare-ImgBed/functions/upload/index.js` | `uploadFileToCnb` 成功后返回 `result.url`（CNB 直链），不再返回 `/file/` 链接；`cnbChannel.returnUrl === false` 时可回退旧格式 |
| `CloudFlare-ImgBed/functions/utils/metadata/metadataView.js` | 新增 `enrichCnbMetadata`：管理端列表接口透出 `CnbUrl` 直链字段 |
| `Sanyue-ImgHub/src/views/AdminDashBoard.vue` | `handleCopy` 新增 CNB 分支：复制链接时用 `metadata.CnbUrl` 直链（originUrl/mdUrl/htmlUrl/bbUrl 四种格式），缺失时回退 `rootUrl` |

### 验证结果

- `node --check` 两个后端文件通过
- `@vue/compiler-sfc` 编译检查 AdminDashBoard.vue 通过
- curl 复现边缘脏缓存命中（text/html）确认根因
- `git diff` 复查仅包含预期改动

### 部署后必须做的两件事

1. **Cloudflare 后台 → 缓存 → Purge Everything**：清掉 `/file/` 路径上的脏缓存，老图片的 `/file/` 兜底链接才能恢复正常 302 跳转
2. **Sanyue-ImgHub 重新 build**：后台"复制链接返回直链"要 build 后才生效（后端上传返回直链不依赖前端 build）

### 修复后的完整流程

```
上传（选 CNB 渠道）
  │
  ├─ POST /upload?uploadChannel=cnb
  ├─ 上传图片本体到 CNB（api.cnb.cool 三步上传）
  ├─ KV 写入记录：key = fullId（如 1789970676695_img3038.webp）
  │    metadata = { Channel: "CNB", CnbUrl: "https://cnb.cool/.../xxx.webp",
  │                 CnbFilePath: "/zzgs219/cdn-img/-/imgs/.../xxx.webp", FileName, FileType ... }
  └─ 接口直接返回 {"src": "https://cnb.cool/.../xxx.webp"} ← 国内直链 ✅

用户访问
  └─ 浏览器直接访问 CNB 直链（国内速度），不经过 Cloudflare ✅

后台管理
  ├─ 文件记录依旧按 fullId 存在 KV 里（缩略图/预览/下载/删除照旧）
  └─ 复制链接 → 复制出 CnbUrl 直链 ✅

兜底：/file/{id} 仍然可用
  └─ 302 跳转到 CnbUrl（需先 Purge 清掉脏缓存）
```
